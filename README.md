# 山行 · 杜牧

循着《山行》的四句诗，走进一座可漫游的体素秋山。石径、白云、山居、木车与霜叶，属于同一个连续的三维世界。

![寒山秋色全景](docs/qa/overview-desktop.png)

## 体验

- 默认进入全景；点击任一句诗，镜头约用 2.1 秒移到对应景物。
- 拖动环顾，滚轮缩放；手机上单指环顾、双指缩放。
- 快速点击会转向最新一句；开始拖动会中止镜头飞行。重复选句可恢复预设构图。
- 「全景」回到初始视角；「循诗入山／走向下一句」依次游览四景。
- 暂停按钮冻结云与落叶，仍可切换和拖动镜头。「简化动态」直接切换视角并停止景物动画，也自动遵循系统减少动态设置。
- 「沉浸」隐藏阅读面板并放大山景，底部仍可选句；按 Esc 退出。
- 诗句按钮支持 Tab、Enter、空格以及方向键、Home、End。三维画面不可用时，仍可读完整诗文并重试。

## 本地运行

使用 Node.js 22.12+ 和 pnpm。当前锁文件由 pnpm 11.23.0 生成。

```bash
pnpm install
pnpm dev --port 5177
pnpm check
pnpm build
pnpm preview --port 4177
```

`dev` 启动开发服务，`check` 执行严格 TypeScript 检查，`build` 检查类型并生成 `dist/`，`preview` 提供生产预览。Vite 使用相对资源路径，可作为静态网站部署。图形、模型、天空和植被均由本地代码生成，无需远程图片、字体或模型。

生产构建中的 Three.js 分块约 505 kB（gzip 约 126 kB），Vite 会提示分块尺寸警告。三维模块按需加载；手机初始化时降低像素密度和树木数量，并关闭阴影。

## 原文与意象

> 远上寒山石径斜，
> 白云生处有人家。
> 停车坐爱枫林晚，
> 霜叶红于二月花。

原文依据：[香港教育局《山行》原文、注释与赏析](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/recommended-passages/KS2_14.pdf)。繁体原文在页面转为简体，保留句序与标点；采用「生处」版本，「生处」一作「深处」。「坐」意为「因为」。

| 诗句 | 共享世界中的区域 | 视角 |
| --- | --- | --- |
| 远上寒山石径斜 | 连通山脚、山腰与山居的石径 | 沿路望向远山 |
| 白云生处有人家 | 山脊云带中的三户山居 | 从前侧看屋舍与云 |
| 停车坐爱枫林晚 | 石径旁的停靠处 | 看木车、旅人与晚照枫林 |
| 霜叶红于二月花 | 同一片枫林中的大枫树 | 靠近红色树冠 |

木车、马匹、旅人及屋舍的具体造型为视觉补充，并非历史场景复原；未指定实际山址。「二月花」是比喻，未在深秋场景中另设春花。

## 项目结构

```text
src/App.tsx       React 阅读面板、导航与图形状态
src/poem.ts       原文、出处、稳定景观 ID 与镜头配置
src/world.ts      Three.js 生命周期、渲染、相机与恢复
src/terrain.ts    共享地形函数、路径节点与地标坐标
src/landscape.ts  程序化地形、树木、山居、木车与动画
src/voxel.ts      方块实例化批次
src/style.css    桌面、手机与沉浸排版
scripts/qa.mjs    agent-browser 浏览器验收
docs/qa/         实际检查结果与截图
```

所有镜头复用同一个场景。React 卸载时取消动画、解绑事件与 ResizeObserver，并释放几何体、材质、实例、阴影和渲染器。`window.__maplePath` 是仅供验收的只读状态快照。

## 浏览器验收

安装可用的 `agent-browser` CLI 并启动生产预览后运行：

```bash
pnpm qa http://127.0.0.1:4177
# 同时验证运行中的开发服务和 React StrictMode：
pnpm qa http://127.0.0.1:4177 http://127.0.0.1:5177
```

脚本使用独立 Chromium 会话，覆盖逐句截图、转场中断、缩放、键盘、暂停、减少动态、沉浸、响应式排版、模拟触控及图形失败恢复。结果写入 `docs/qa/results.json` 和 `docs/qa/accessibility.json`。本次覆盖与限制见 [验收记录](docs/acceptance.md)；模拟手机画幅和触控不代表真实手机验证。
